# Импорт цен INVITRO

Источник: https://www.invitro.ru/analizes/for-doctors/emanjelinsk/

## Модель

Импорт не перезаписывает прайс клиники. Внешний каталог и услуги разделены:

- `price_import_runs` — время, статус и статистика каждого импорта;
- `external_price_products` — нормализованные поля и полный исходный JSON каждой позиции последнего снимка;
- `service_price_links` — связь внешней позиции с услугой один-к-одному;
- `services` — цена, предоплата, длительность и видимость, которые администратор меняет вручную.

Актуальным считается последний импорт со статусом `success`. Неуспешный импорт не подменяет предыдущий каталог. Одинаковые UUID, повторённые в ответе в разных группах, схлопываются в одну позицию.

## Запуск

После миграции:

```bash
DATABASE_URL=... pnpm prices:invitro
```

Проверено на сайте: 2 660 анализов и 350 уникальных комплексов, всего 3 010 позиций. Клиент получает страницы по 100 позиций с паузой 150 мс, обычными HTTPS-запросами без авторизации. Необходимы нормальный browser User-Agent и Referer публичной страницы города.

Периодический запуск выполняется по расписанию сервера, например раз в сутки вне рабочего времени. Не запускать параллельные импорты из нескольких процессов. Частота должна оставаться умеренной; при отказе или изменении правил сайта импорт останавливается, а не обходится защита источника.

## CRM

`/crm/tseny` доступен ролям `admin` и `senior`.

- «Обновить каталог INVITRO» запускает импорт вручную.
- «Каталог INVITRO» ищет по названию, коду и категории, фильтрует анализы/комплексы и листает по 50.
- «Добавить в прайс» создаёт выключенную услугу с ценой источника и нулевой предоплатой либо связывает уже существующую с точным совпадением названия.
- В «Прайсе клиники» меняются цена, предоплата, длительность и видимость. Предоплата не может превышать цену.
- «Вернуть цену INVITRO» меняет только основную цену услуги; предоплата и остальные настройки сохраняются.

Изменения пишутся в `audit`. Списание цен в старые записи не происходит задним числом: в `bookings.service` остаётся снимок условий записи.
